🌟 What Is spectromood?

spectromood is a desktop-friendly application that listens to speech and shows you the emotion carried in the voice itself. Instead of guessing from the words alone, it looks at how something is said: the pitch, the rhythm, the energy, the pauses, and the shape of the sound over time.

The application draws a spectrogram — a colorful picture of sound — and pulls out a set of voice measurements alongside it. Those measurements are compared to a baseline that belongs to you. That comparison is what makes spectromood different from generic emotion tools: it learns what your normal voice looks like, so a quiet, tired sentence is not mistaken for a sad one.

Once the comparison is made, a decision model called Cloudflare Clef reviews the evidence and produces the final emotion call. Everything happens locally on your machine, inside a Docker container, with a realtime dashboard that updates as you speak.

✨ Key Features

  • Realtime emotion dashboard — watch results appear live while you speak or while an audio clip plays.
  • Spectrogram plots — a visual map of frequency and energy across time, so you can see what the model sees.
  • Voice feature analysis — prosody measurements including pitch movement, loudness, speaking rate, and pause behaviour.
  • Your own personal baseline — record a short calibration sample and every later result is judged against it.
  • Cloudflare Clef decision model — a transparent decision layer that weighs the spectrogram and feature evidence together.
  • Voice activity detection (VAD) — silence and background noise are trimmed automatically, so only real speech is analysed.
  • Docker-only packaging — one installation path, the same behaviour on every Windows computer.
  • FastAPI backend — a lightweight local service that keeps the dashboard responsive.

🪟 Step-by-Step Setup for Windows

Step 1 — Install Docker Desktop

spectromood runs inside Docker, which is a free program that packages the application and everything it needs into one self-contained unit. Download Docker Desktop from the official Docker website, run the installer, and accept the default options. When it finishes, restart your computer if the installer asks you to.

Step 2 — Start Docker Desktop

Open Docker Desktop from the Start menu. Wait until the small whale icon in the taskbar shows that Docker is running. This usually takes less than a minute. spectromood cannot start until Docker is fully awake.

Step 3 — Download spectromood

Visit this link to download the application. The releases page lists the newest version at the top. Save the file to a folder you can find again, such as your Downloads folder or a new folder called spectromood on your Desktop.

Step 4 — Launch spectromood

Open the folder where you saved the download. Start the application the way the release describes — the release page notes the exact command or file for the current version. Docker will prepare the environment the first time, which takes a few minutes. Later starts are much faster.

Step 5 — Open the dashboard

When the startup finishes, open your web browser and go to the local address printed in the window. The realtime dashboard appears there. Bookmark it so you can return to it any time Docker is running.

Good to know: the first launch downloads the container image, which can take a while on a slow connection. Keep the window open until it says the service is ready. Closing the window early simply means starting again — nothing is broken.

🎛️ Using the Dashboard

The dashboard is arranged in three simple areas: a microphone panel, a results panel, and a baseline panel.

  • Record a baseline first. Speak normally for the suggested amount of time — read something aloud, describe your day, or just talk. spectromood stores the voice features of that sample as your reference point.
  • Start a live session. Press the start button and speak. Voice activity detection ignores the silences between your sentences, so only speech is analysed.
  • Read the spectrogram. The plot scrolls as you speak. Brighter bands show where energy is concentrated. You do not need to interpret it to use the app — it is there so you can see the evidence behind each result.
  • Check the emotion call. The decision model returns the most likely emotion together with how strongly the evidence supports it. Results are always relative to your baseline.
  • Review past results. Recent analyses are kept in the dashboard so you can compare one recording against another.

🧠 How the Decision Model Works

Three pieces of evidence feed into Cloudflare Clef. First, the spectrogram plot captures the overall texture of the speech. Second, the voice features describe prosody in numbers — pitch range, loudness variation, timing, and pauses. Third, your baseline provides the reference that makes those numbers meaningful for you.

Clef weighs the three together and produces a single decision with a confidence level. Because the baseline is yours, results stay useful even if your voice is naturally quiet, deep, fast, or accented.

🐳 Why Docker-Only?

Speech processing involves audio libraries that behave differently from machine to machine. By shipping spectromood as a Docker container, every Windows user gets the exact same environment — the same audio handling, the same version of every component, and the same results. There are no hidden dependencies to install, no version conflicts, and no risk that an update to something else on your computer breaks the application.

🔧 Troubleshooting

The dashboard will not open

Confirm Docker Desktop is running and shows a healthy status. Then start spectromood again and wait for the readiness message before opening your browser.

No sound is being detected

Check that Windows has allowed microphone access for your browser. Speak a little closer to the microphone and confirm the level meter moves while you talk.

Results look unstable

Record a fresh baseline in the same room and at the same distance from the microphone you normally use. Background noise and microphone placement affect voice features more than most people expect.

The first start was very slow

That is the container image downloading. Once it is stored locally, later starts take only a few seconds.

❓ Frequently Asked Questions

Do I need to know how to code?

No. You need Docker Desktop, a browser, and the download link. The dashboard does the rest.

Does my audio leave my computer?

spectromood runs locally in Docker. Your recordings are processed on your own machine.

Why compare against a baseline?

Because emotion in speech is personal. A calm voice for one person is a flat voice for another. The baseline removes that ambiguity.
